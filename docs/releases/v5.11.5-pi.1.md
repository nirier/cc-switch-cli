This verification release adds automatic model discovery when creating a Pi provider with an OpenAI-compatible base URL and API key. Save the provider in the TUI with an empty model list, or run:

```sh
cc-switch --app pi provider add --name "My Gateway" \
  --base-url https://gateway.example/v1 --api-key "$PROVIDER_API_KEY"
```

The release includes direct-download binaries and SHA-256 checksums. GitHub Actions verifies model discovery against a mock OpenAI-compatible endpoint before publishing.
